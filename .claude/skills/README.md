# Custom Skills

This directory is reserved for *user-authored* Claude Code skills (`SKILL.md` files).

Third-party skills (Anthropic-official, community plugins) are *not* included
in this repository because of license / attribution constraints. Install them
from the [official Anthropic plugin marketplace](https://github.com/anthropics/claude-code/blob/main/plugins/README.md)
or [awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code) as needed.

The author's own skills (if any) will be added here in a future revision.
