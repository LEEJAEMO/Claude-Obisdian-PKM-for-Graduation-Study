# 연구 세션 저장

세션에서 일어난 모든 것을 캡처해서 다음 세션이 정확히 이어갈 수 있게 저장한다.

## 실행 순서

### Step 1: 컨텍스트 수집

이 세션에서 아래를 확인:
- 분석한 논문 (제목, 결론, Obsidian 저장 여부)
- 작성/수정한 노트 (경로)
- 해결한 것과 해결 못 한 것
- 새로 생긴 질문

### Step 2: 세션 파일 작성

경로: `~/.claude/session-data/YYYY-MM-DD-research-session.tmp`
(오늘 날짜를 실제 날짜로. 같은 날 여러 번이면 `-2`, `-3` suffix 추가)

형식:

```markdown
# Research Session: YYYY-MM-DD

**연구 주제**: [오늘 주로 다룬 주제]
**저장 시각**: [현재 시각]

---

## 오늘 한 작업

[무엇을 했는가 — 2~4문장. 다음 세션에서 맥락 없이 읽어도 이해되게]

---

## 완료된 것 (근거 포함)

- **[항목]** — 확인: [어떻게 확인했는가. "저장했다"가 아니라 구체적 근거]

완료된 것이 없으면: "이번 세션에서 완료 확인된 항목 없음"

---

## 안 된 것 / 막힌 것

[가장 중요한 섹션. 다음 세션이 같은 걸 재시도하지 않게]

- **[시도]** — 실패 이유: [정확한 이유. "안 됐다"가 아니라 구체적으로]

없으면: "막힌 항목 없음"

---

## 아직 시도 안 한 것

- [아이디어 / 접근법 — 다음에 시도할 것]

없으면: "없음"

---

## Obsidian 파일 상태

| 파일 경로 | 상태 | 메모 |
|----------|------|------|
| `경로/파일.md` | 완료 / 진행중 / 미시작 | [메모] |

파일을 건드리지 않은 경우: "이번 세션 파일 수정 없음"

---

## 결정 사항

- **[결정]** — 이유: [왜 이렇게 결정했는가]

없으면: "주요 결정 없음"

---

## 미해결 질문

- [질문]

없으면: "없음"

---

## 다음 세션 첫 번째 할 일

[정확히 무엇을, 어디서부터. 다음 세션이 생각 없이 바로 시작할 수 있게]

정해지지 않은 경우: "다음 할 일 미정 — '아직 시도 안 한 것'과 '미해결 질문' 참고"
```

### Step 3: Vault 정합성 검증 (/lint 실행)

볼트에 대규모 수정이 있었다면 먼저 `python scripts/vault_lint.py`를 실행하고
결과를 세션 파일의 "Vault 상태" 섹션에 요약한다.
- 스키마 위반 0 확인
- my_context 미입력 카운트 기록 (복리 관리)
- 고아 노트 신규 발생 여부

위반이 발견되면 수정 또는 "다음 세션 첫 번째 할 일"에 반영.

### Step 4: Obsidian Research Log 생성 (/wiki-update 호출)

세션 파일 작성 완료 후 자동으로 `/wiki-update`를 실행해서
Obsidian의 `1. Project/대학원 공부/2. 연구 (Research)/Research Log/YYYY-MM-DD.md` 에도 저장한다.

### Step 5: 사용자에게 확인

파일 내용을 보여주고:
```
세션 저장 완료: [실제 경로]
Obsidian Research Log: [실제 경로]

내용이 정확한가? 수정할 것이 있으면 말해줘.
```

사용자 확인을 기다린다. 수정 요청 시 반영한다.

---

## 주의사항

- 각 세션은 별도 파일 — 기존 파일에 append하지 않는다
- "안 된 것" 섹션이 가장 중요 — 다음 세션이 같은 실패를 반복하지 않게
- 완료 항목은 근거 없이 쓰지 않는다
