# 설명 연습 — 시험 전 연습용

다음은 예측 기출이나 자동 답변이 아닌 자기점검이다. 시험의 후속 서술형에서는 AI를 쓰지 않고 직접 답한다. 자료 열람 가능 여부는 실제 안내를 따른다.

파일을 확인한 다음 화면을 보지 않고 90초 동안 설명한다. 다시 파일과 대조해 틀린 내용을 고친다.

1. 누구의 어떤 업무 문제를 해결했고 무엇을 제외했는가?
2. 입력 → 핵심 처리 함수 → 출력은 어떻게 이어지는가?
3. 어떤 구조/라이브러리를 왜 택했고 더 단순한 대안은 무엇인가?
4. 실제로 확인한 실패 입력, 수정 위치, 재검증 결과는 무엇인가?
5. 데이터·보안·성능·정확성 측면에서 깨지는 조건과 보호 동작은 무엇인가?
6. 시간이 더 있다면 무엇을 먼저 바꾸며 이유는 무엇인가?

모르는 것을 그럴듯하게 채우지 않는다. 질문에 해당하는 실제 결정·파일·검증·한계를 연결한다. 여섯 질문은 실제 후속 서술형 문항이 아니다.
