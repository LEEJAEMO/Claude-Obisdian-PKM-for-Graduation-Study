# 설계 출처와 한계

- 사용자 소유 PKM의 M-006, M-010, M-018, T-005, T-006, T-007, T-015에서 범용 작업 원칙만 새로 작성했다. 원문·raw·개인 경로·회사 자료·연구 수치·첨부는 포함하지 않는다.
- M-REQ, M-QA 및 S-*는 이번 이식 목적의 종합 제안이다. 원래 PKM의 검증된 모듈로 사칭하지 않는다.
- [Cofa 공식 평가 소개](https://www.getcofa.com/ko/about), [Probe 공식 안내](https://www.getcofa.com/ko/probe): 기술·의도·인지, 결과·과정·설명을 함께 확인하는 방향.
- [Cofa 제작진 공개 영상](https://www.youtube.com/watch?v=CLpN3zl8noQ): 16:14~19:43 요구 탐색, 22:39~24:53 평가 축, 25:25~26:57 과설계, 31:04~33:18 기존 도구 재사용. 2026-10-30 공개 한국어 자동 자막 대조. 자동 자막의 고유명사·표현 오인식 가능. 정확한 배점·비공개 루브릭은 확인되지 않았다.
- [MCP lifecycle](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle), [tools](https://modelcontextprotocol.io/specification/2025-11-25/server/tools), [stdio](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports): 이 구현은 2025-11-25 도구 조회 하위 범위만 제공한다.
- [OpenAI 공식 MCP 설정 문서](https://learn.chatgpt.com/docs/extend/mcp): CLI/config 예시의 근거. 시험 환경의 기능 노출·권한·버전은 별도다.

시험 안내 PDF는 로컬에서만 확인했고 배포하지 않는다. 라이브러리 카드는 실제 새 업무에서 검증되지 않았으며 출처 대조와 도구 테스트를 업무 성과와 구분한다.
