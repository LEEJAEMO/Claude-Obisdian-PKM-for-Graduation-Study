# M-001 — 강의노트 작성 루틴

> **재사용 목적**: 반복 수행되는 강의노트 작성 task의 단일 정본.
> **이 문서가 강의노트 깊이·언어·구조의 정본** — `.claude/workflows/lecture-note.md` 와 `/notes-digest` 명령은 이 문서를 참조한다.

## 트리거

- 사용자가 `/notes-digest --transcript ... --pdf ...` 호출
- 또는 자연어로 "강의노트 작성해줘" + 녹취록/PDF 첨부

## 1차 소스 원칙

- **녹취록(TXT)이 1차 소스**, PDF는 보조
- PDF가 여러 주차에 걸쳐 있으므로 **해당 주차 범위만** 노트에 반영
- "이전 주차 복습이라 생략" 하지 말 것 — 교수가 발화했으면 `[복습]` 태그와 함께 포함

## 단계 요약

| Step | 작업 |
|------|------|
| 0 | 인자 파싱 — transcript / pdf / pdf2 / memo, 누락 시 사용자 확인 |
| 1 | 본 M-001 + `14. Specs/workflows/lecture-note.md` 읽어 subject/약칭/접두어 확정 |
| 2 | 과목·날짜·주차·교수명 파악 (파일명 또는 녹취록 첫 줄에서) |
| 2.5 | **2주차 이상이면 이전 주차 노트 반드시 Glob/Read** — 마지막 섹션 확인, `prev_lecture` / `next_lecture` 양쪽 갱신 |
| 3 | PDF가 있으면 pypdfium2로 페이지 PNG 추출 (복수 PDF는 `_1R_p`, `_2R_p` 구분) |
| 4 | 녹취록 `【スライド N】` 기준 섹션화 → PDF·메모와 대응. 발화 세그먼트 비례로 depth 조정 (§ 깊이 가이드라인 참조) |
| 5 | `note-organizer` 에이전트 호출 — 본 M-001 § 깊이 가이드라인 + § 언어·표기 정책 명시적 전달 |
| 6 | 저장 경로 확인 — `0. Main Vault/Obsidian Vault/1. Project/대학원 공부/1. 과목 (subject)/강의노트 (Lecture Note)/` |
| 7 | 이전 주차 노트의 `next_lecture` 갱신 + 새 노트 `prev_lecture` 확인 |
| 8 | (선택) 강의 영상에 강사 라이브 마크업·필기가 있으면 M-003 으로 슬라이드 PNG 추출 |

## 출력 파일명

## 깊이 가이드라인 (depth standard)

> 본 섹션이 강의노트 작성의 **핵심 정본**. 5/7 노트(`2026-05-07 ID 5주차 (Professor A).md`)가 본 가이드라인의 표준 예시.

### 분량 기준

| 강의 시간 | 노트 분량 (목표) |
|---|---|
| 60분 강의 | 600~900줄 |
| 90분 강의 | 1100~1500줄 |
| 120분 강의 | 1500~2000줄 |

핵심 섹션 1개당 80~150줄 (단순 정의·도식 위주 섹션은 30~50줄로도 가능).

### 패턴 1 — 단계 분해 유도 (n단계 패턴)

수식·알고리즘 유도가 있는 섹션에서 **결론 식만 박스로 던지는 것을 금지**. 다음 형식을 따른다:

```
#### 1단계 — [한 단계의 명칭]
[수식·논리]
> "교수 인용 — 이 단계의 동기" (Professor A, X/Y 녹취 MM:SS~)

#### 2단계 — ...
...

#### N단계 — [최종 결과]
$$\boxed{ 최종 식 }$$

#### 식의 의미 분해
- $\Phi^T\Phi$: ...의 의미 (몇 차원 / 무엇을 측정)
- $\Phi^T\vec{f}$: ...의 의미
- 직관: "..."의 형태로 한 줄 요약
```

**참조 예시**:
- `2026-04-30 ID 4주차 (Professor A).md` §III-3-A (b) 가중치 결정 (7단계 유도)
- `2026-05-07 ID 5주차 (Professor A).md` §(b) 가중치 결정 (7단계, 동일 패턴)
- `2026-05-07 ID 5주차 (Professor A).md` §III-3-B (d) 오차역전파 (연쇄 미분 7단계 + 코드 예)

### 패턴 2 — "왜 이 형태인가" 동기 설명

새 식·개념을 도입할 때 **결론 직전에 동기를 1~2문장으로 명시**:

> 동기: "기존 방법의 약점은 X. 이를 해소하기 위해 Y 를 도입한다."

또는 교수 발언 인용으로 동기를 대체:

> "이대로 두면 ~한 문제가 생기죠. 그래서 ..." (Professor A, X/Y 녹취 MM:SS~)

### 패턴 3 — 비교 표 + 콜아웃

같은 개념의 두 변형, 또는 헷갈리기 쉬운 두 정의를 만나면 **표 + callout** 으로 명시화.

예시 (5/7 노트 §(f) 커널 회귀):
```
> [!info] 가우시안 커널 vs §(e) 가우시안 RBF 기저
> 둘은 같은 함수 형태로 헷갈리기 쉽지만 의미가 다르다.
> - **§(e) RBF 기저**: 한 샘플 중심에서 거리에 따라 감쇠하는 **하나의 기저 함수**.
> - **(f) 가우시안 커널**: 두 점 사이 거리에 따라 감쇠하는 **유사도 함수**.
```

### 패턴 4 — 콜아웃 종류별 용법

| 콜아웃 | 용법 | 예시 |
|---|---|---|
| `> [!info]` | 두 개념 비교, 추가 정보 (위 RBF vs 커널) | 정의 명료화 |
| `> [!important]` | 핵심 결론, 시험에 나올 만한 한 줄 | TL;DR 직후 |
| `> [!warning]` | 함정·헷갈림 (인덱스 이중 사용 등) | 인덱스 $i$ 가 샘플과 기저에 모두 등장하는 경우 |
| `> [!note]` | 보조 사실, 옆길로 새는 디테일 | "왜 신경망에는 LOO-CV 효율 공식이 없는가" |

### 패턴 5 — 강의 인용 형식

```
> "교수 발언의 한국어 의역. 일본어 원문 그대로가 아닌 자연스러운 한국어로." (Professor A, X/Y 녹취 MM:SS~MM:SS)
```

- **타임스탬프 정확성**: 녹취록의 슬라이드 시작 시각 ± 10초 이내
- **의역 우선**: 일본어 직역체("~입니다", "~되지요" 등 일본 어투)는 한국어로 다듬기
- **빈도**: 핵심 섹션당 2~4개 인용. 너무 많으면 흐름 끊김

### 패턴 6 — "다음 섹션 연결" 인용

섹션 마지막에 강의 흐름의 **다음 단계로의 자연스러운 전환**을 1~2줄로:

```
#### (b)로의 연결
기저 함수 집합이 사전 선택된 후, 남은 작업은 "$\vec{w}$를 어떻게 결정할 것인가". Professor A는 36:55 무렵에 *"이 $w_i$를 어떻게 정할지가 다음 이야기입니다"* 로 §(b)로 넘어간다.
```

이 패턴이 노트의 **선형성**을 만든다 — 사용자가 위에서 아래로 읽으며 강의 흐름을 그대로 재현 가능.

### 패턴 7 — 시각적 anchor

- 핵심 섹션 시작에 슬라이드 이미지 1장 (`![[..._pXX.png|560]]` + 캡션)
- 표지·목차·참고문헌 슬라이드는 생략
- 강의 영상에서만 보이는 강사 라이브 마크업이 핵심이면 M-003 으로 추출

## 언어·표기 정책

### 한국어 우선 — 한자 학술 용어 금지

본문은 **한국어로 풀어쓴다**. 영어 병기는 OK. 일본어 한자 학술 용어는 **사용 금지**.

매핑 (자주 쓰는 것):

| 일본어 한자 | 한국어 (영어) |
|---|---|
| 代理モデル | 대리 모델 (surrogate model) |
| 線形回帰 | 선형 회귀 |
| 基底関数 | 기저 함수 (basis function) |
| 重み | 가중치 |
| 過学習 | 과학습 (overfitting) |
| 汎化能力 | 일반화 능력 (generalization) |
| 正則化 | 정규화 |
| 多項式 / 三角関数 / 放射基底 | 다항식 / 삼각함수 / 방사 기저 (RBF) |
| カーネル / 内積 | 커널 / 내적 |
| ニューラルネットワーク / 線形層 / 非線形層 | 신경망 / 선형층 / 비선형층 |
| 誤差逆伝播 | 오차역전파 (backpropagation) |
| 活性化関数 | 활성화 함수 |
| 説明変数 / 自由度 | 설명 변수 / 자유도 |
| 等間隔 / ランダム / 一様射影 | 등간격 / 랜덤 / 균일 사영 (Latin Hypercube) |
| 勾配 / 事前 | 경사 (gradient) / 사전조사 |
| 空間充填率 | 공간 충진율 |
| 演習 | 연습 (또는 과제) |
| Professor A / Professor B / Professor C / Professor D / Professor E / Professor F | Professor A / Professor B / Professor C / Professor D / Professor E / Professor F (인명 한국어 음역) |

### 한자 보존이 필요한 영역 (예외)

다음만 한자 그대로:
- `frontmatter.lecture_material` (실제 PDF 파일명)
- `frontmatter.prev_lecture` / `next_lecture` wikilink (실제 노트 파일명)
- 본문 wikilink 대상 — 단 display alias 로 한국어 표시 추가 권장
  - 예: `[[2026-04-23 ID 3주차 (Professor A)|3주차 (Professor A)]]`

근거: 사용자 메모리 `feedback_no_kanji.md`. *"사용자가 복습용으로 노트를 읽는데 한자/일본어 표현이 본문에 산재하면 시각적 노이즈로 작동해 가독성 저하."*

### 인용문 내 일본어 의역

녹취록은 일본어지만 인용문은 **한국어 의역**으로:

❌ Bad: `> "Hat ついてるやつが代理関数。" (Professor A)`
✅ Good: `> "Hat 붙어 있는 게 대리 함수, 붙어 있지 않은 게 실제 평가 대상이라고 생각해 주세요." (Professor A, 4/30 녹취 37:14~37:30)`

## 이미지 삽입 규칙

- 주요 다이어그램: `![[접두어_p##.png|560]]` + 한국어 캡션
- 보조: `![[접두어_p##.png|400]]` + 캡션
- 텍스트 전용 슬라이드 (표지/목차/참고문헌): 생략
- 위치: 해당 섹션 설명 텍스트 **앞** (시각적 anchor 역할)

## 좋은 노트의 표준 예시 (참조)

| 노트 | 본받을 부분 |
|------|------|
| `2026-04-30 ID 4주차 (Professor A).md` | §III-3-A (b) 7단계 유도 / §(c) 역행렬 조건 표 / §(g) 커널 회귀 단계 분해 |
| `2026-05-07 ID 5주차 (Professor A).md` | 1217줄, 90분 강의 표준 분량. 모든 핵심 섹션이 단계 분해 + 의미 분해 + 인용 포함 |
| `2026-05-07 ID 5주차 (Professor A).md` §III-3-B (d) | 오차역전파 7단계 + Python 클래스 예 + vanishing gradient 메커니즘 |

새 강의 작성 전 위 두 노트의 핵심 섹션을 1~2개 살펴보고 깊이 감각 보정 권장.

## 대용량 녹취록 처리

- 녹취록 TXT가 30000 tokens 이상이면 Read 단일 호출 불가
- `offset` / `limit` 으로 분산 읽기 (예: 400라인씩) → 슬라이드 구간별로 읽기 권장
- 90분 강의 = 약 2000줄 녹취록 — 4~5번에 나눠 읽으면 충분
