# T-005 — 경로 누락과 표시 깨짐 구분

적용: FileNotFoundError path 한글 경로 파일 없음 mojibake

비대상: 콘솔 표시만 보고 파일 인코딩을 일괄 변경하지 않는다

출처 ID: T-005. 일반화·재작성: 2026-10-30.
검증 수준: 원문 대조한 설계; 새 과제에서의 효능은 미검증.

조건: Python에서 경로가 없다는 오류가 나고 터미널에서는 한글도 깨져 보인다.

현재 파일이 실제 위치에 있는지, 직전 단계에서 이동/이름 변경이 있었는지 먼저 확인한다. 허용된 작업 폴더 안에서 파일명을 좁혀 검색한다. 후보가 여러 개면 첫 결과를 임의 선택하지 않는다.

검증: 선택 경로가 하나로 확정됐는지, 해당 파일을 정상 열 수 있는지 확인한다. 표시 인코딩과 파일 존재 여부를 독립적으로 검사한다. 전체 디스크나 사적 디렉터리를 자동 탐색하지 않는다.
