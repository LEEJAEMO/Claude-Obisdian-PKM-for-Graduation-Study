# T-006 — 완료 보고와 실제 산출물 대조

적용: false report 자체 보고 완료 validation 검증 missing 파일 링크

비대상: 보고 문장을 실행·저장 증거로 취급하지 않는다

출처 ID: T-006. 일반화·재작성: 2026-10-30.
검증 수준: 원문 대조한 설계; 새 과제에서의 효능은 미검증.

증상: AI의 완료 보고와 실제 파일·링크·실행 결과가 다르다.

직접 파일을 열고 출력 경로·내용·링크 대상·명령의 종료 상태를 대조한다. 줄 수나 파일 수가 필요하면 실제로 세고, 실행되지 않은 검사는 미실행으로 기록한다. 생성하지 않은 이미지·파일명을 꾸며 링크하지 않는다.

최소 수정 후 같은 검사를 재실행한다. 검증 통과 범위와 아직 확인하지 못한 통합 동작을 구분한다. 이 카드는 과거 해결 기록의 일반화이며 새 환경에서 항상 재현된다는 보장이 아니다.
