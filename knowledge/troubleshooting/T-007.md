# T-007 — Windows Python 콘솔 인코딩 오류

적용: UnicodeEncodeError cp949 stdout 한국어 python encoding

비대상: 파일 손상이나 경로 누락을 같은 원인으로 단정하지 않는다

출처 ID: T-007. 일반화·재작성: 2026-10-30.
검증 수준: 원문 대조한 설계; 새 과제에서의 효능은 미검증.

조건: Windows 콘솔에서 비ASCII 문자를 출력할 때 UnicodeEncodeError가 발생한다.

Python을 UTF-8 모드로 실행한다: python -X utf8 script.py. 파이프 입출력도 필요하면 프로세스의 PYTHONIOENCODING=utf-8을 사용한다. 코드에서 표준 스트림을 설정하는 경우 실제 스트림 지원 여부를 확인한다.

검증: 한글과 기호를 포함한 작은 출력·파일 되읽기를 각각 확인한다. UTF-8 모드는 이미 손상된 텍스트를 복구하지 않는다. 원본을 대량 재인코딩하지 않는다.
