# M-006 — 원본 보존과 데이터 처리 계약

적용: 데이터 CSV raw processed pipeline 입력 검증 집계 export

비대상: 과제에 없는 물리 모델이나 장비 단위를 도입하지 않는다

출처 ID: M-006, M-018. 일반화·재작성: 2026-10-30.
검증 수준: 원문 대조한 설계; 새 과제에서의 효능은 미검증.

원본 입력과 처리 결과를 구분한다. 원본의 의미·열·단위·키·시간 범위·결측·중복 정책을 먼저 확인한다. 원본 파일을 덮어쓰지 않는다.

일반 업무에는 load → validate → transform → export 구조를 사용한다. 원래 M-006의 load → fit → plot → export는 측정 분석용이므로 fitting/plot이 필요할 때만 채택한다.

최소 검증: 입력 행수 = 유지 + 제외 + 검토 대상. 사유가 겹치면 우선순위 또는 복수 사유 정책을 정의한다. 0과 결측을 구분하고 그룹 키 충돌을 확인한다. 수치·원인은 실제 출력과 근거 범위 안에서 설명한다.
