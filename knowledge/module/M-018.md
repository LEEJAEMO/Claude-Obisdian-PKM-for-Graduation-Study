# M-018 — 입력 역할 확인과 복잡도 선택

적용: 품질 QC raw 가공 비교 model complexity 대조 데이터

비대상: 장비별 수치 임계값과 SiC 측정 결론을 새 업무에 전용하지 않는다

출처 ID: M-018. 일반화·재작성: 2026-10-30.
검증 수준: 원문 대조한 설계; 새 과제에서의 효능은 미검증.

파일명만 보고 원본인지 처리 결과인지 판단하지 않는다. 내부 열·헤더·생성 단계로 역할을 확인하고 비교용 결과를 입력에 섞어 중복 처리하지 않는다.

단순한 기준 해법을 먼저 만들고 복잡한 모델/기능은 과제 요구나 새 입력의 실제 개선이 있을 때 추가한다. 더 많은 파라미터가 결과를 더 타당하게 만드는 것은 아니다.

데이터 의미·단위·대조군이 불명확하면 원인 확정을 보류한다. 불확실도를 보고할 경우 입력 산포, 모델 추정 오차, 가정의 차이를 분리한다. 여기에는 원래 장비의 QC 컷이나 물성 수치가 포함되지 않는다.
