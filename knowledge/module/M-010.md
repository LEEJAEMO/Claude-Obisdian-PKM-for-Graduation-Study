# M-010 — 작은 프로젝트와 단계별 구현

적용: scaffold 구조 architecture 단계 구현 simulation 재개 status

비대상: 과제와 무관한 수치 솔버·환경·연구 설정은 가져오지 않는다

출처 ID: M-010. 일반화·재작성: 2026-10-30.
검증 수준: 원문 대조한 설계; 새 과제에서의 효능은 미검증.

과제의 핵심 처리, 입력/설정, 사용자 표시를 필요에 따라 분리한다. 작은 프로젝트에 과도한 폴더나 계층을 강제하지 않는다.

알려진 작은 사례 → 주요 기능 → 다른 입력 → 최종 통합 순서로 진행한다. 설정값과 출처는 한곳에서 확인할 수 있게 한다. 불확실한 값은 임의로 채우지 않는다.

재개에는 templates/STATUS.md의 완료·실패·다음 명령만 남긴다. 기록된 완료 상태를 현재 파일과 대조한다. 실행 파일 위치는 현재 작업 디렉터리보다 __file__ 기준으로 계산하면 이식성이 좋아진다.
