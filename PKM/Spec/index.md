# Spec — 분류 인덱스와 작성 가이드

## 먼저 이 지침을 읽는다

- 문서 단위: 요구·기능 단위의 살아 있는 명세.
- 작성할 때: 요구나 기능 범위가 새로 생기거나 분리될 때.
- 필수 내용: 목표/사용자, 확인한 요구와 출처, 가정/열린 질문, 입력·출력, 제약·비목표, 수용 기준(R-001 등).
- 연결/운영: 관련 Plan 문서, Project의 구현 위치, Evidence와 연결한다. 구현하며 요구가 바뀌면 현재 명세를 개정하고 변경 이유를 Decisions/Log에 남긴다.
- 파일명: S001-짧은-주제.md부터 시작한다. 도구의 new는 다음 번호를 계산한다.
- 새 문서를 만든 뒤 아래 목록에 제목/파일과 현재 절대경로를 등록한다.
- 개별 .md와 이 index 모두 첫 줄에 현재 절대경로를 표시한다.
- 본문은 task의 실제 정보로 작성한다. 아직 하지 않은 구현·검증을 완료로 쓰지 않는다.
