# Modules — 분류 인덱스와 작성 가이드

## 먼저 이 지침을 읽는다

- 문서 단위: 실제로 반복한 절차 하나.
- 작성할 때: task 안에서 같은 절차를 반복해 재사용 가치가 생겼을 때.
- 필수 내용: 적용/비대상, 입력, 단계, 출력, 검증, 관련 Project 코드와 실제 사용 근거.
- 연결/운영: 미리 큰 지식 창고를 채우지 않는다. 검증되지 않은 절차를 성공 이력으로 쓰지 않는다.
- 파일명: M001-짧은-주제.md부터 시작한다. 도구의 new는 다음 번호를 계산한다.
- 새 문서를 만든 뒤 아래 목록에 제목/파일과 현재 절대경로를 등록한다.
- 개별 .md와 이 index 모두 첫 줄에 현재 절대경로를 표시한다.
- 본문은 task의 실제 정보로 작성한다. 아직 하지 않은 구현·검증을 완료로 쓰지 않는다.
