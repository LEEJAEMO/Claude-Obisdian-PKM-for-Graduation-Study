# PKM — 과제를 함께 이해하는 진입점

실제 구현은 Project/, 작업 이해와 재개는 PKM/에서 한다. 먼저 아래에서 필요한 분류를 고르고 그 index의 지침을 읽은 뒤 개별 문서를 작성한다.

| 폴더 | 먼저 열 파일 | 내용 |
|---|---|---|
| Spec | [Spec/index.md](Spec/index.md) | 목표·요구·입출력·가정·수용 기준 |
| Plan | [Plan/index.md](Plan/index.md) | 구현·검증 작업과 관련 코드 |
| Status | [Status/index.md](Status/index.md) | 현재 상황·다음 행동·재개 |
| Decisions | [Decisions/index.md](Decisions/index.md) | 선택·대안·변경 이유 |
| Evidence | [Evidence/index.md](Evidence/index.md) | 실제 검사·출력·미실행 |
| Log | [Log/index.md](Log/index.md) | 의미 있는 작업 구간·변화의 흐름 |
| Modules | [Modules/index.md](Modules/index.md) | task 안의 반복 절차 |
| Troubleshooting | [Troubleshooting/index.md](Troubleshooting/index.md) | 실제 오류·원인·수정·재검증 |
| System | [System/index.md](System/index.md) | 도구·설치 정보·이력·검사 |

현재 상황은 Status의 최신 기록에서 읽는다. 필요할 때 brief로 관련 문서의 실제 발췌를 모아 본다. 전체 폴더를 매번 읽지 않는다.
모든 작성 Markdown은 첫 줄에 실제 절대경로를 적고, 요구/작업 ID 및 Project 경로로 필요한 문서를 연결한다.
