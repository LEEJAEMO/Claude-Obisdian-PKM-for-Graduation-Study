# Log — 분류 인덱스와 작성 가이드

## 먼저 이 지침을 읽는다

- 문서 단위: 의미 있는 작업 구간의 흐름.
- 작성할 때: 진행 전환·요구 변경·구현 단위·중요 사건이 있을 때.
- 필수 내용: 구간/시각, 시작 목표, 실제 수행, 변경 이유, 결과, 연결된 Spec/Plan/Decision/Evidence/Status.
- 연결/운영: 모든 대화·토큰·편집을 복제하지 않는다. 자동 events.jsonl은 저장 사건이며 사람이 읽는 이 작업 로그를 대신하지 않는다.
- 파일명: L001-짧은-주제.md부터 시작한다. 도구의 new는 다음 번호를 계산한다.
- 새 문서를 만든 뒤 아래 목록에 제목/파일과 현재 절대경로를 등록한다.
- 개별 .md와 이 index 모두 첫 줄에 현재 절대경로를 표시한다.
- 본문은 task의 실제 정보로 작성한다. 아직 하지 않은 구현·검증을 완료로 쓰지 않는다.
