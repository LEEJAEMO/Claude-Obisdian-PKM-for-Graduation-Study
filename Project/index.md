# Project — 실제 과제 구현 위치

실제 코드·입력의 작업 사본·테스트·실행 설정·처리 결과·제출용 산출물은 이 폴더에서 만든다.
현재 과제의 구조에 맞게 src/tests/data/output 등을 필요할 때 추가하며, 특정 프레임워크를 미리 강제하지 않는다.
제공된 task 파일을 복사했다면 기존 상대경로 구조를 확인하고 이 폴더에서 실행한다. 실행 환경이 고정 경로를 요구하면 정상 제공 설정을 확인한다.
사용자와 진행을 공유하는 과정 기록은 ../PKM의 해당 분류에 쓰고 실제 코드/출력의 이 폴더 경로와 연결한다.
여기서 생성·갱신하는 모든 Markdown도 첫 줄에 자신의 현재 절대경로를 표시한다.

문서 최상단에는 절대경로·과제 루트 기준 상대경로·최초 작성 주체/모델/근거·최근 수정 주체/모델/근거를 기록한다. 상세 규칙은 루트 AGENTS.md를 따른다.
